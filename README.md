# AMR Systems free Odoo apps

Free, open source Odoo modules by [AMR Systems](https://amrsystems.pl).
One folder per module, one branch per Odoo series (`20.0`, ...).

| Module | Description | License |
| --- | --- | --- |
| [amr_app_sections](amr_app_sections/) | Organize the Odoo Enterprise home menu into collapsible, per-user sections. | LGPL-3 |

## Installation

Copy the module folder for your Odoo series into your addons path and install
it from the Apps menu, or install it from the
[Odoo app store](https://apps.odoo.com/apps/modules/browse?author=AMR%20Systems).

## Issues and support

Bug reports and feature requests: [GitHub Issues](https://github.com/AMR-Systems/odoo-apps-free/issues)
or support@amrsystems.pl. Support is best effort, the apps are free.
