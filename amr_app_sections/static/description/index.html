App Sections

Organize your home menu into collapsible sections.

When many apps are installed, the home menu becomes one long wall of icons. App Sections lets every user group those icons into named, collapsible sections: keep daily apps on top, tuck the rest away, and find everything faster. It changes presentation only, never permissions, and each user has their own layout.

Why teams like it

  • Personal layouts. Every user arranges their own home menu. Nothing changes for anyone else.
  • Follows you everywhere. The layout is saved on the server, so it is the same in every browser and on every device.
  • Honest and safe. Apps never disappear: anything not placed in a section waits in the catch-all section, and access rights are never touched.
  • Free and open source. No account, no tracking, no external services, no paid version.

How it works

  1. Open the home menu and click Add section. You get a personal section plus a catch-all with all your apps.
  2. Drag apps between sections, or use the Move to section menu on any tile. It works on touch screens too.
  3. Rename sections, reorder them, collapse the ones you rarely need. Everything is saved as you go.
  4. Changed your mind? Restore default layout brings back the standard home menu.

Supported languages

English Polski

Each user sees the interface in their own language.

Good to know

  • Requires Odoo 20 Enterprise (Odoo.sh or on-premise). The home menu is an Enterprise feature, so the module is not for Odoo Online or Community.
  • Licensed under LGPL-3. Free, with best effort support and no fees, ever.
  • Uninstalling removes all saved layouts and leaves the standard home menu exactly as it was.
